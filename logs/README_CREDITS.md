# Credits and Acknowledgements

This project was developed using the **Road Damage Dataset: Potholes,
Cracks and Manholes** and trained with GPU acceleration through **Google
Colab**.

## Dataset

The road-damage images used in this project come from:

**Giordani, Enrico; Arcioni, Lorenzo; Gil-Martín, Manuel; and Marini,
Marco Raoul.**\
*Road Damage Dataset: Potholes, Cracks and Manholes.* Zenodo.

-   Dataset record: https://zenodo.org/records/17834373
-   DOI: https://doi.org/10.5281/zenodo.17834373

The dataset contains road-surface images annotated for three classes:

-   Pothole
-   Crack
-   Manhole

The dataset creators and contributors are gratefully acknowledged for
collecting, annotating, and making this data available for research and
development.

Please refer to the dataset record for its current version, full
description, and licensing terms. If you redistribute the dataset or
derived materials, follow the dataset's applicable license and
attribution requirements.
